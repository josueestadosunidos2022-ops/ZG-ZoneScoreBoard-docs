# ZoneScoreBoard Client 1.0.1

## English
- Optional client presentation for ZoneScoreBoard's TAB panels; the dedicated server JAR remains a separate file and is not bundled in a client modpack.
- Decorative panel rows do not receive player heads. Real player rows can display heads, ping bars and milliseconds with compatible server 3.5.1+ data.
- Client TOML controls row height, spacing, accent color, opacity and section symbol. The GODIELAND pack uses the supplied blue/violet settings.
- Falls back to the normal player list outside a recognized ZoneScoreBoard layout; no required ZoneCore or ZoneRanks client dependency.
- Includes root pack.mcmeta metadata. Protected public build, unchanged resources and mod ID; no sources, mappings or private server information. Forge 1.20.1, client only, Java 17+.

## Español
- Presentación opcional de los paneles TAB de ZoneScoreBoard. El JAR de servidor dedicado es independiente y no se incluye en el modpack de cliente.
- Las filas decorativas no muestran cabezas. Las filas de jugadores reales admiten cabeza, barras de ping y milisegundos con datos compatibles del servidor 3.5.1+.
- El TOML de cliente regula altura, separación, acento, opacidad y símbolo. El modpack conserva el ajuste azul/violeta recibido.
- Usa el TAB normal si no reconoce el diseño ZoneScoreBoard; no exige ZoneCore ni ZoneRanks en el cliente.
- Incluye pack.mcmeta raíz. Compilación pública protegida con recursos y mod ID conservados, sin fuentes, mappings ni información privada. Forge 1.20.1, solo cliente, Java 17+.
